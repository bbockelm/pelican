## pelican mcp serve

Start the MCP server on stdio

### Synopsis

Start the Model Context Protocol server, reading JSON-RPC requests from stdin
and writing responses to stdout. Logs go to stderr so they cannot corrupt the
protocol stream.

```
pelican mcp serve [flags]
```
